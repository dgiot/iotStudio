### 5 条最强证据

| # | 证据 | 等级 | 直接用途 |
|---|------|------|----------|

| 3-2 | **GB/T 22239-2019（等保 2.0）**：要求在网络边界/重要节点做安全审计，"网络安全审计措施缺失"为**高风险项**，审计即"对流量数据进行分析" | 一级 | 被动监听是**履行等保义务**，非违规 |
| 3-3 | **GA/T 1390.5-2017 + IEC 62443-3-3 SR 6.1**："向授权人员和/或工具提供**以只读方式**访问审计日志"、持续监测 | 一级/二级 | "只读获取数据"是中外工控安全标准的明文要求 |
| 3-4 | **《网络安全法》第二十一条**：网络运营者有"监测、记录网络运行状态"的法定义务 | 一级（法律） | 合法性总依据 |
| 3-5 | **油气行业同构先例**：塔里木油田中间数据库"单向接收 SCADA 数据"、油气管道 SCADA"双网卡旁挂 OPC 采集 + 单向网闸"、华北油田边缘网关 MQTT 桥接、Heritage Petroleum"OPC 镜像 + 数据二极管" | 二级/三级 | "不改造既有系统、旁挂获取数据副本"是行业成熟实践 |

### 五步论证模板（可直接用于附件②）

1. 合法性基础：网安法 21 条要求监测记录网络运行状态（3-4）
2. 国标认可部署形态：GB/T 20945-2023 并联部署（3-1）
3. 只读获取是标准明文：GA/T 1390.5 / IEC 62443-3-3（3-3）
4. 对生产系统零影响：并联非串联（无阻断点）、不改 A11 配置、不注入数据（libpcap 捕获/发送 API 分离）、监听口无 IP、故障不影响主链路（SPAN 优先级低于业务流量 / 无源 TAP）
5. 合规边界：**甲方书面授权 + 合同范围 + 数据归属甲方 + 最小化留存加密脱敏**——授权链条是合规充分必要条件，技术形态本身不是"黑客行为"

### 反方证据（评审可能反问，需主动披露）

- 端口镜像拥塞时丢包/延迟（建议吞吐评估 + 丢包告警，必要时 TAP 形态）
- 镜像流量含原始报文，**已按网安法 40-45 条落实数据保护**：国密 SM2/SM3/SM4 加密存储与传输（国密安全平台已实现）、最小化留存（仅保留与物模型匹配的测点数据）、原始报文脱敏后处置
- 旁路监测不能替代系统自身身份鉴别/访问控制（定位为审计补充措施）
