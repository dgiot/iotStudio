## 编译流程（对外材料）

```bash
cd docs/报价/对外/tex
xelatex -interaction=nonstopmode <文件名>.tex   # 双次编译
mv <文件名>.pdf ../                              # PDF 移回对外/
rm -f *.aux *.log *.out *.toc                    # 清理辅助文件
```

## 语言纪律（对外材料硬约束，详见记忆 external-material-language-rules）

1. 不讲敏感技术手段——无"逆向/帧还原/帧解析/逐帧解析"字样，只讲"协议开发对接/协议解析"，接入需甲方授权凭证（IP、端口、用户名、密码）
2. 不讲自家内部技术手段（本体论、知识图谱等），方案通俗化
3. 实现口径统一——无"SPAN/被动监听/被动采集/Npcap/BPF/抓包/网络捕获"旧表述，统一为"静态 IP 客户端主动采集 + 动态 IP 抢占原地址端口桥接转发"
4. "监听"仅保留固定词"路由监听"（报价书板块命名），其余一律"采集/读取"（如 8889 端口对接、双路采集分流、轻量只读采集组件）
5. 引用纪律：79 号文"据公开报道"、未核实标准不引、厂商数字标注来源；NIST SP 800-82r3 原文含 SPAN 字样可引用（加引用来源）
6. 附件级材料不写价格（金额指向报价书）
