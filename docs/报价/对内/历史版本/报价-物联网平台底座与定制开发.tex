\section{报价说明}

\begin{enumerate}[leftmargin=*]
  \item 本报价按两大功能域组织：\textbf{边缘中枢汇聚功能}（平台侧汇聚、存储、分发）与\textbf{边缘数据采集和历史计算功能}（边缘采集、动态感知、流式计算、历史计算）。
  \item 报价基准按 \textbf{2,500 元/人天} 估算，含税；实际按最终方案范围与工期核定。
  \item 报价不含：硬件（服务器/采集机/存储）、第三方授权费用（DCS 厂家配合费）、现场差旅、税费。
  \item 边缘采集遵循 \textbf{不修改 DTU、不影响 A11 正常使用} 的搭桥原则，零侵入采集。
\end{enumerate}

\section{一、边缘中枢汇聚功能}

\subsection{1.1 功能描述}

边缘中枢汇聚功能承担平台侧的数据汇聚、存储、分发与管控能力：
\textbf{多协议接入汇聚}（10+ 协议）、\textbf{时序与关系存储}（TDengine/PG 双库 + 三级存储）、\textbf{告警与推送}（MQTT/HTTP 双通道）、\textbf{平台管控}（设备/资产/报表）、\textbf{安全可信}（国密）与\textbf{管理后台}（Vue3）。

\section{二、边缘数据采集和历史计算功能}

\subsection{2.1 功能描述}

边缘数据采集和历史计算功能承担边缘侧的数据采集、动态感知、流式计算与历史计算：
\textbf{边缘采集}（多协议采集 + 入库前流水计算）、\textbf{作业区适配层}（A11 桥接/OPC DA/Modbus 感知/网关适配，搭桥手术三件套）、\textbf{流式计算}（15 种公共算法 + 每作业区 ≥1 种定制算法）、\textbf{历史计算}（历史统计/回放/报表计算）与\textbf{术前体检}（8 维度 + 台账）。
