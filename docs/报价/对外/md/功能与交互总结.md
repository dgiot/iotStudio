## 二、典型交互闭环

### 告警闭环
```
采集异常 → 规则引擎判定 → POST /Alarm → 🔴告警列表
→ 点击确认 → PUT status=acknowledged → 升级链 → 处置归档
```

### 数据查询
```
浏览器 → GET /Telemetry?where=device_id&order=-ts&limit=100
→ ECharts 实时曲线渲染
```

### 边缘同步
```
IO服务器 → CommBridge :53002 → MQTT :1883 → Rule Engine → SQLite/PG → 前端
```

### Modbus 扫描
```
输入IP段 → SlaveScanner.find_active(1,247) → PointScanner.scan_range(0,30)
→ OilfieldModelMatcher.match_points() → 物模型自动匹配 → 前端表格
```

### IO 服务器克隆
```
wmic 进程清单 → 配置文件读取 → 1:1 克隆模拟环境
```
