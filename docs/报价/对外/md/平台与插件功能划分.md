# 基础平台 vs 通道插件 — 功能划分

> 底座提供通用能力（开源、不计价），插件实现油田定制（自研、计价）

---

## 一、基础平台功能（底座自带，不单独计价）

### dgaiot 底座 (Erlang/OTP, 36 应用)

| 功能 | 组件 | 说明 |
|------|------|------|
| MQTT Broker | dgiot :1883 | 千万级设备接入，QoS 0/1/2，Topic ACL |
| Parse 数据 API | Parse :1337 | REST CRUD，认证，RBAC 角色权限 |
| 用户认证 | \_User 表 | 登录/登出，sessionToken，角色树 |
| 菜单导航 | Menu 表 | 动态菜单生成，按角色裁剪 |
| 页面视图 | View 表 | 页面级权限控制 |
| 权限规则 | Rule 表 | 菜单/按钮/数据三级权限 |
| PostgreSQL | PG :7432 | 关系持久层，主数据唯一源 |
| TDengine | TD :6041 | 时序存储引擎，冷热分层 |
| Nginx | :80 | 反向代理，统一入口 |
| WebSocket | :8083 | 实时推送 |
| OTP 监督树 | Erlang/OTP | 进程监控，故障自动恢复 |
| 设备影子 | Shadow | 状态机: init→auth→online→normal/alarm→offline |
| 本体论引擎 | Ontology | 实体-关系-约束存储与查询 |

## 三、一句话总结

```
基础平台 (开源底座)  →  MQTT、API、认证、存储、前端框架 → 不计价
通道插件 (自研)      →  协议适配、采集策略、算法、界面 → 按板块计价
```

所有材料统一引用此划分。
