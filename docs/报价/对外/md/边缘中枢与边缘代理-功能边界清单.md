# 边缘中枢与边缘代理 — 功能边界清单

> 用途：消除板块一/二/三功能重叠，所有材料统一引用此清单。
> 原则：边缘代理 = dgiot\_lite 底座 + 插件（IO 服务器, 生产网）；边缘中枢 = dgaiot 底座 + 插件（麒麟 DMZ 区）——互不重叠。
> 后端统一 Python 插件 · 前端一套插件体系，代理和中枢共享 · dgaiot 提供基础设施层

---

│  Python 应用后端 (共享)   │           │  Python 应用后端 (共享)       │

| 层 | 技术 | 部署位置 | 说明 |
|----|------|---------|------|
| **前端** | Vue3 + Element Plus | 代理 + 中枢 | ✅ 同一套代码，按部署位置加载不同视图 |

## 插件功能（油田定制，计价）

### 一、边缘代理插件（dgiot\_lite + 插件 → IO 服务器上运行）

| 功能 | 说明 | 对应代码 | 报价板块 |
|------|------|---------|---------|
| **协议解析** | A11 专有协议、Modbus RTU/TCP、OPC DA、IEC104、MQTT、HTTP 等 10+ 协议统一适配 | `src/protocols/` 下 11 个 .py | 板块三-1 |
| **双路采集** | 静态 IP：客户端主动连接旁路取数；动态 IP：抢占原 IP:端口桥接透明转发 | `commbridge_server.py` | 板块三-4 |
| **设备动态感知** | 设备上线/下线/增删自动发现，10 家网关厂家适配（注册帧识别+透传解析） | `gateway_dynamic.py` `modbus_auto_identify.py` | 板块三-3 |
| **动态调频** | 异常加密（10min→秒级）、低峰降频、弱网退避、错峰调度 | `zone_adapter.py` | 板块四-4.1-4 |
| **断网缓存与补传** | 断网时本地 SQLite 缓存，恢复后按时序补传，去重幂等 | `zone_adapter.py` | 板块四-4.1-5 |
| **物模型自动配点** | G1-G8 油水井物模型（64 点/井），A11 既有点位原样映射 | `models/thing_model.py` | 板块四-4.2-6 |
| **作业区适配层** | ZoneAdapter 编排器：A11 桥接/OPC DA 直采/Modbus 感知/本机业务四子模块 | `zone_adapter.py` | 板块三-2 |
| **非标协议接入** | 视频 RTSP、智能仪表、工程器械等按需适配 | `protocols/video_rtsp.py` 等 | 板块四-4.1-7 |
| **数据上报** | 通过 MQTT 上报给边缘中枢（只上报，不存储、不计算、不展示） | `push/mqtt_pusher.py` | 板块二-1 |

**边缘代理不负责**：数据存储、流式计算、告警判定、报表生成、任何 UI 展示。

---

**部署位置**：作业区 IO 服务器（Windows Server 2016，生产网 11.66.12.x）
**一句话**：dgiot\_lite 底座 + 油田定制插件 → 把数据采下来、推上去。不存、不算、不展示。

### 二、边缘中枢插件（dgaiot + 插件 → 麒麟 DMZ 区运行）

**部署位置**：DMZ 区（麒麟 Linux V10，D:\ai\kylin\workspace\dgiot-kylin\）
**一句话**：dgaiot 底座 + 油田定制插件 → 把数据汇起来、算出来、存下来、呈现出来。

| 功能 | 说明 | 对应代码/服务 | 报价板块 |
|------|------|-------------|---------|
| **MQTT 消息汇聚** | dgiot 千万级 Broker，接收 100+ 边缘代理数据，QoS 0/1/2 分级，Topic ACL 权限控制 | dgiot :1883 | 板块一-4 |
| **流水计算引擎** | 15 种内置算法 + 每作业区定制注册，数据入库前完成判定与告警 | `stream_engine.py` `flow_learner.py` | 板块一-5 |
| **告警规则引擎** | 四级告警（Critical/Error/Warning/Info）、去重合并、升级链、确认/清除双动作 | `alarm_engine.py` `rules_engine.py` | 板块一-6 |
| **混合存储** | TDengine 3.x 时序（冷热分层）+ PostgreSQL 15+ 关系（主数据唯一源）+ SQLite 边缘降级 | `storage/tdengine.py` `postgres.py` | 板块一-3 |
| **可视化规则编排** | 拖拽式配置触发条件与动作，预制模板，版本管理 | `rules_engine.py` + 前端 StreamView | 板块一-7 |
| **驾驶舱大屏** | 深色底 C 位链路拓扑，KPI 卡片墙（链路健康率/采集完整率），告警滚动列表，秒级刷新 | `DashboardView.vue` `SystemOverview.vue` | 板块一-8 |
| **设备管理** | 设备台账、五态生命周期、详情六页签（台账/实时/历史/告警/趋势/采集日志） | `DeviceListView.vue` `DeviceDetailView.vue` | 板块一-8 |
| **告警中心** | 四级告警分级列表、工单闭环（发现→确认→处置→归档）、通知记录 | `AlarmListView.vue` | 板块二-8 |
| **数据服务** | 多粒度报表（日/月/年）、时间轴拖拽回放、REST API 数据接口 | `ReportsView.vue` `cloud_functions.py` | 板块一-8 |
| **可视化** | 采集链路拓扑、拖拽式仪表盘组态、GIS 地图层级下钻 | `TopologyView.vue` `HmiView.vue` | 板块一-8 |
| **自动化** | 规则联动（采集触发→条件判定→动作执行）、场景编排、批量配置下发 | `rules_engine.py` `shadow.py` `FdeWizardView.vue` | 板块一-7 + 二-7 |
| **系统管理** | 用户/角色/权限（三员分立）、角色化界面裁剪（领导/调度/运维）、审计日志全留痕 | `UsersView.vue` `auth.py` | 板块一-9 |
| **全链路安全** | 国密 SM2/3/4 加密、设备身份认证、RBAC 权限、防篡改审计 | `crypto/sm_crypto.py` `system_api.py` | 板块一-9 |
| **边缘汇聚对接** | EdgeHub 部署、Topic 规范、QoS 分级配置、边缘节点双向消息同步 | `edge_hub_channel.py` `edge_hub_push.py` | 板块二-1 |
| **分级存储策略** | SSD 热数据 / HDD 温数据 / 归档冷数据，数据生命周期自动管理 | `tiered_storage.py` | 板块二-2 |
| **信创适配** | 麒麟 V10 + 飞腾/鲲鹏 + 达梦/金仓 + 国产浏览器全栈适配 | 麒麟部署包 | 板块五-4 |

**边缘中枢不负责**：直接采集设备（协议适配在代理侧完成）、设备侧的本地缓存。
