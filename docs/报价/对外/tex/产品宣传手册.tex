\section{产品亮点}

\begin{enumerate}[leftmargin=*]
  \item \textbf{不替代A11，不改变现有设备}——A11继续运行，本系统并行新通道，零风险搭桥
  \item \textbf{按作业区定制采集策略}——全油田不是一种节奏，每区独立定制频率/算法/优先级
  \item \textbf{定制化流水计算}——15种内置算法+每区注册定制算法，数据入库前完成判定
  \item \textbf{断网补传进度可视化}——链路断了数据不丢，恢复后自动补传，业界独有
  \item \textbf{Python+Vue3全栈}——源码交付，甲方自主运维，不被供应商锁定
  \item \textbf{信创全栈适配}——麒麟/统信UOS · 飞腾/鲲鹏 · 达梦/金仓
\end{enumerate}
