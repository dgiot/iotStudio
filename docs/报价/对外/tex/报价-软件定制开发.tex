\section{项目背景与报价定位}

大庆油田当前的数据采集体系基于 A11 平台运行。随着电参数字化、工况智能诊断、设备健康预警等应用的深化，油田日益增长的\textbf{精细化、定制化运行需求}（逐井逐工况的差异化采集、高频异常秒级预警、动态设备统一感知）与 A11 \textbf{标准固化的体系}（统一点位、统一频率、统一配置，全系统一种节奏）之间的矛盾愈发突出：100 余个作业区、6000 余座井场的设备类型、DCS/PLC 厂家组合、运行工况各不相同，标准服务已无法满足精细化运行需求，对报警预警、生产优化等核心业务的落地形成制约——\textbf{瓶颈不在算法（算法在局地试点已验证），而在数据底座的采集密度与灵活性}。

与此同时，本项目面临\textbf{双重保留挑战}：其一，\textbf{A11 继续保留运行、继续承载原有生产业务}——不改 DTU 配置、不改变其任何端点行为（本项目不替代、不影响）；其二，\textbf{保留现有系统全部既有配置}（已建点位、量程频次、物模型与 A2/A5 资产体系）\textbf{及与既有业务系统的集成关系}（数据交换、接口对接不中断、不重建）。新系统只能在上述双重约束内以\textbf{桥接镜像}方式并行插入——这是本项目技术路线的根本前提。同时，项目\textbf{硬件投入极少}：新增仅 2--3 台服务器（生产网边缘计算 1 台、DMZ 短期缓存 1 台、办公网汇聚中枢 1 台，可按现场合并为 2 台），其余设施——IO 服务器、网络、存储、既有设备——\textbf{全部利旧}；本系统软件部署于既有 IO 服务器，与 A11 服务同机共存、互不影响。

更深层的问题是：\textbf{市场上通用平台产品与标准服务花钱即可获得，但能满足油田差异化生产需求的定制服务——逐作业区适配、逐工况调优、逐井定制算法——花钱也买不到}。油田信息化建设长期受数据标准不统一、设备协议不兼容困扰，大量项目重复建设、运维成本居高不下；设备厂家技术支持以天计响应，逐井调优、逐工况适配更无从谈起；统建体系供给单一，外部服务商难以进入，差异化需求只能靠零散小项目逐个补缺，既无规模效益也无质量保障。需求侧真实存在，供给侧无人能交付，这正是本项目存在的价值。

本项目以\textbf{"软件产品 + 边缘部署 + 标准化采集模块 + 按作业区定制 + 交付保障"五层分列}的模块化报价体系破解该瓶颈：软件产品一次开发、多项目复用，边缘能力按现场落地，采集模块标准化交付，作业区定制按"区数 $\times$ 单价"透明计价，交付保障独立核算守住质量红线——总价与官方测算金额对齐（725.04 万元），既满足差异化生产需求，又为商务谈判保留充分操作空间。

\section{报价说明}

\begin{enumerate}[leftmargin=*]
  \item \textbf{服务模式：五层分列的模块化报价}——板块一（边缘中枢软件产品，按"套"计价）、板块二（边缘汇聚与系统对接，按部署工作量计价）、板块三（边缘采集与历史计算模块，标准化组件）、板块四（多作业区定制开发，按"作业区数 $\times$ 单价"）、板块五（项目整体交付与品质保障，按"1 套"计价）。
  \item \textbf{计价方式：产品化模块报价}——告别功能点计价，采用客户可理解的产品目录式报价（引擎/框架/平台/中间件/控制台），各模块独立标价、可逐项审视；定制服务明确"按厂家定制 / 按作业区定制"粒度，便于增减作业区时快速核算。
  \item \textbf{通用能力与自主化增强边界}：MQTT 接入、消息中间件、规则引擎、可视化组件等通用能力源自成熟开源组件\textbf{直接复用}（不计价、不重复开发）；本报价计价的是开源能力之上的\textbf{自主化增强}——百万级测点高并发支撑、国密算法套件、全栈信创适配、协议插件化引擎、防篡改审计与完整源码交付，即开源能力满足不了、需自主可控解决的部分（自研/外协/复用分类见附件④：自研 790 人天、外协 550 人天、开源复用 110 人天）。
  \item \textbf{总价与官方测算对齐}：本报价总计 \textbf{725.04 万元}，与官方费用测算（估算功能点法）金额一致——同一项目范围、同一总价，计价方式调整为产品化模块报价，增强商务可操作性。
  \item 全栈口径（前后端一体），不拆分前端/后端；报价不含：硬件、第三方软件授权（含信创环境时序库企业版授权，按甲方信创环境另行核算）、DCS 厂家配合费、非试点区实施、信创适配现场环境（测试机）。
  \item \textbf{A11 保留运行，不影响原有业务}：本项目是基于 A11 现有采集架构的\textbf{能力增强与扩展}，\textbf{不替代、不改动 A11}——A11 继续保留运行、继续承载原有生产业务，本项目仅以路由监听旁路方式并行采集（搭桥原则，零侵入、可回退，失败不影响原链路），原业务投资零损失；\textbf{对 A11 原有业务零影响列入验收指标}（见 7.2）。
  \item 交付方式：全栈源码 + 全套文档（需求/设计/测试/用户手册），自动化测试通过，甲方团队跟学共建、可独立运维。
\end{enumerate}
