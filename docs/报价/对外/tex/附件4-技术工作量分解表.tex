\section{编制说明}

\begin{enumerate}[leftmargin=*]
  \item \textbf{用途}：落实评审会要求"按技术服务方式量化工作量、明确界定自研模块与外协边界"（五条硬性要求之五），本表按\textbf{协议开发、安全加固、主数据对接}等模块逐项分解工作量（人天），与报价书《软件定制开发报价书》的板块结构相互印证、金额口径一致。
  \item \textbf{人天口径}：8 小时标准人天，含需求分析、方案设计、编码实现、测试验证、现场实施与联调全流程；现场环境（野外井场、偏远站点、防爆区、弱网）下人天已含差旅与现场调优成本。
  \item \textbf{团队规模}：18--20 人（架构设计 2 人、开发 12 人、测试 3 人、实施 2--3 人），2026-08 至 2026-11-30 交付周期（约 4 个月），板块间并行开发，总工作量约 \textbf{1,450 人天}。
  \item \textbf{与官方测算折算}：官方功能点测算软件规模 4,088.57 FP（按 1,773.33 元/FP 折合 725.04 万元），与本表 1,450 人天折算约 2.8 FP/人天，处于行业含高复杂度协议适配与现场实施项目的合理区间（参考 2.5--4 FP/人天），工作量核算充分且可审计。
\end{enumerate}

\section{自研 / 外协 / 开源复用边界}

\begin{enumerate}[leftmargin=*]
  \item \textbf{外协（限三类，响应评审会要求）}：协议适配（非标协议开发对接、厂家 SDK 适配）、安全认证（国密集成、渗透测试）、主数据对接（数据湖接口联调）。外协工作量合计 550 人天，占比 37.9\%。
  \item \textbf{自研}：采集引擎、流式计算、告警闭环、存储策略、平台底座、测试验证等核心能力全部自研，工作量合计 790 人天，占比 54.5\%。
  \item \textbf{开源组件直接复用}：TDengine 社区版（时序存储）、FastAPI（Web 框架）、pymodbus/asyncua（协议库）等成熟开源组件直接复用，不重复开发，工作量合计 110 人天，占比 7.6\%；复用组件许可（如 AGPL 3.0）在交付前完成法务合规评估与必要处理，确保自主可控（硬性要求之四）。
  \item \textbf{自主可控承诺}：所有定制开发内容均交付完整源代码，不依赖黑盒商业软件；信创环境时序库企业版授权为第三方软件授权，按甲方信创环境另行核算（与报价书边界声明一致）。
\end{enumerate}

% ═══════════════════════════════════════════
\section{与报价书的对应关系}

\begin{itemize}[leftmargin=*]
  \item 本表工作量按"技术服务方式"量化（评审要求），报价书按"产品化模块"计价（商务可操作）——同一项目范围的两套度量口径，金额同源（725.04 万元），工作量可逐项审计。
  \item 界面呈现类功能（监控大盘、资产全生命周期界面等）不在本表工作量内，由《界面功能表》单独核算、另行报价。
  \item 二期（其他作业区/其他油田推广）工作量按"作业区数 $\times$ 单价"扩展，不在本期 1,450 人天内。
\end{itemize}
