# 面向油气田实时分析的边缘流计算引擎 — 深度研究报告

> 研究时间: 2026-07-27 | 用途: 时序数据采集与应用管理系统项目流式引擎选型依据

---

## 核心发现

1. **eKuiper (LF Edge)** 是目前最成熟的工业边缘流处理引擎—核心包仅 4.5MB，内存约10MB，树莓派3B+达12,000 msg/s
2. Go EdgePipe 吞吐量是 Flink 的 3.8x (320K vs 84K events/s)，内存 42MB vs 1.2GB
3. 油气场景推荐 Hopping Window + eKuiper SQL 规则引擎 + TDengine 流存一体

## 边缘引擎对比

| 引擎 | 核心体积 | 内存 | 吞吐量 | 滑动窗口 | 许可证 |
|------|---------|------|--------|---------|--------|
| **eKuiper** | 4.5 MB | ~10 MB | 12,000 msg/s(Pi) | 4种 | Apache 2.0 |
| **Bytewax** | ~15 MB | 0.4 GB | 高 | 3种 | Apache 2.0 |
| **Flink 1.18** | >200 MB | ≥1.2 GB | 84,000/s | 全类型 | Apache 2.0 |
| **Go EdgePipe** | — | ~42 MB | 320,000/s | 支持 | 商业 |

## 油气专用场景

- 抽油机示功图边缘实时分类: 每冲次延迟<50ms，产量+15%，循环次数-29%
- 管线泄漏 XGBoost 检测: 准确率 97.09%
- 断网自治: DFG-AI架构维持 98-99% 现场作业能力

## 选型建议

- 通用边缘实时报警: **eKuiper** (4.5MB, SQL规则引擎)
- Python ML推理流: **Bytewax** (Rust内核, NumPy/PyTorch集成)
- 复杂SQL流处理: **RisingWave** (PostgreSQL兼容, 存算分离)
- 边缘时序+流引擎一体化: **TDengine 3.x** (内置流引擎)
