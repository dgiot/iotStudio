## 九、约束规则

1. **生产网只出不进**：所有写操作限制在 dgiot :53002 独立通道
2. **A11 零影响**：原 A11 采集链路全保留，不修改任何 A11 配置
3. **端口隔离**：新增采集走 :53002，不与 :53001 共享端口
4. **下发纪律**：频率限制在 CommBridge 轮询间隙 (200ms 窗口)，批量 <100 条，间隔 >5s
5. **CPU 红线**：边缘代理 CPU <5%，延迟 <20μs
6. **Oracle 只读**：查询通过 WinRM 中继，不直连 OLEDB
7. **DQYTPROD 凭证**：仅用于 SELECT，不执行 DML/DDL
