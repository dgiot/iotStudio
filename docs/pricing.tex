\section{报价前置条件与免责}

\begin{enumerate}[leftmargin=*]
  \item 以上报价基于标准版（$\leq$ 500 台设备），超出需重新评估
  \item 仅覆盖市场主流协议兼容设备，非标协议另行评估
  \item 服务器硬件由客户自行采购，我方不承担硬件采购与维护
  \item 设备与服务器间网络连通性由客户保障
  \item 数据库采用开源免费版本（TDengine Community + PostgreSQL），客户无需购买 License
  \item 本报价表为脱敏版本，最终价格以双方签署的商务合同为准
  \item 报价有效期 30 个自然日
\end{enumerate}
